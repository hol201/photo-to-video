# Запуск Space

1. Создайте аккаунт на https://huggingface.co/join.
2. Создайте новый Space с SDK Gradio.
3. Выберите ZeroGPU, если эта опция доступна аккаунту.
4. Загрузите `app.py`, `README.md` и `requirements.txt` из этой папки.
5. Дождитесь сборки Space.
6. Откройте URL вида `https://USER-SPACE.hf.space` с телефона.

Обычный бесплатный CPU Space не сможет нормально запускать CogVideoX. Если ZeroGPU недоступен или очередь слишком большая, потребуется платная GPU-конфигурация либо API-провайдер.
