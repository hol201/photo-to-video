# Photo → Motion

Mobile-friendly image-to-video demo powered by CogVideoX-5B-I2V and Hugging Face ZeroGPU.

The Space uses the official CogVideoX model and requires a ZeroGPU-capable Hugging Face account/Space. GPU access is shared and may be queued.
