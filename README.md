# Photo → Motion

Личный интерфейс для создания короткого видео из фотографии и текстового промпта. Проект рассчитан на запуск с телефона: бесплатный режим выполняется в Google Colab на временном облачном GPU, поэтому домашний компьютер с видеокартой не нужен.

## Быстрый запуск с телефона

1. Откройте приложение: https://hol201.github.io/photo-to-video/
2. Нажмите **Запустить бесплатно в Google Colab**.
3. В Colab откройте меню **Runtime → Change runtime type → T4 GPU**, если GPU ещё не выбран.
4. Запустите ячейки сверху вниз.
5. В ячейке загрузки выберите фотографию из телефона.
6. Введите prompt на английском языке.
7. Дождитесь генерации и скачайте `photo-to-motion.mp4`.

Прямой notebook находится в репозитории: `notebooks/cogvideox-i2v-colab.ipynb`.

## Модель

Используется CogVideoX-5B-I2V через Diffusers. Модель принимает фотографию и текстовый prompt. Бесплатный GPU в Colab не гарантируется: доступность, длительность сессии и объём памяти зависят от текущих ограничений Google.

## Режим Runway

В приложении также оставлен платный режим Runway API. API-ключ не хранится в GitHub. Он вводится локально в браузере и сохраняется только в `localStorage`. Для запуска Runway нужен ключ и баланс у Runway Developer.

## Почему генерация не выполняется на GitHub Pages

GitHub Pages размещает только статические HTML, CSS и JavaScript-файлы. Он не предоставляет GPU для запуска CogVideoX. Поэтому Pages используется как удобный стартовый экран, а сама модель запускается в Colab.

## Ограничения мобильного режима

Google Colab может отключить бесплатный GPU или завершить сессию. CogVideoX создаёт короткий ролик и может работать несколько минут. Если T4 недоступен, повторите попытку позже или используйте платный Colab/GPU-сервис.

## Безопасность

Не загружайте в публичные ноутбуки конфиденциальные фотографии. Не помещайте API-ключи в GitHub, notebook или JavaScript.
