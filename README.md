# Photo → Motion

Личный интерфейс для генерации короткого видео из фотографии и текстового промпта через Runway API.

## Важно о ключе

Ключ **не хранится в репозитории и не публикуется в GitHub Pages**. GitHub Pages отдаёт JavaScript-код посетителю, поэтому любой ключ внутри `app.js` был бы раскрыт. Для личного использования ключ вводится в разделе «Настройки API» и сохраняется только в `localStorage` вашего браузера.

## Публикация

Сайт разворачивается GitHub Actions workflow в Pages из ветки `main`.

## Runway API

Интерфейс использует официальный endpoint image-to-video и модель `gen4_turbo`. Если браузер блокирует прямой запрос политикой CORS, потребуется небольшой serverless-прокси: ключ будет храниться в секретах серверной функции, а GitHub Pages останется только интерфейсом.

## Ограничения

- Фотография: до 5 МБ.
- Длительность: 2–10 секунд в зависимости от выбранной модели.
- Стоимость генерации определяется тарифом Runway.
- Не загружайте конфиденциальные фотографии на чужие или общедоступные компьютеры.
